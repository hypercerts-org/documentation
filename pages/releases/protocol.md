The protocol major and minor version follows the [Hypercerts Lexicon releases](/releases/lexicon). A new major version can also come from a breaking change to the Lexicon package alone, as in 2.0, where the records did not change; each release's notes say whether existing records are affected. These notes explain the purpose and integration impact of each release; the Lexicon changelog records the detailed package changes. Component release histories have their own versions on the [Releases overview](/releases).
