# Hypercerts SDK Releases

**Under development.** The new Hypercerts SDK has not been released. There is no current package version or changelog to display yet.

The SDK will participate in coordinated protocol major/minor releases, with independent patch versions. When its repository and release process are available, this page will import that changelog and the release cards will show its published version.

See [Client Integration](/client-integration) for available integration material and [Changes](/changes) for the protocol release history.
